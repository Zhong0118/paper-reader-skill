# Scoped reading and figure handling validation

## Baseline and updated instruction simulation

A read-only evaluator used the existing skill before edits, then reread the revised skill. These are instruction-level simulations, not real-PDF execution or statistical reliability claims.

| Case | Baseline | Updated decision |
|---|---|---|
| Abstract-only → long-term note | Archive attempted external-context completion; internal completeness ambiguous | Save existing coverage and gaps without extra research |
| Eq.4-only teacher → full method | Missing-content rule competed with flat completed_stages | Recover scope, reuse Eq.4, explain remaining method |
| arXiv v2 → v3 | No version invalidation protocol | Recheck affected evidence and dependent content, preserve user notes |
| Caption readable, diagram unreadable | Generic uncertainty rule only | Record caption-only access; no guessed arrows or false saved-image claim |
| Theory/survey critique | Not baseline-tested | Choose proof or review-method criteria, no fabricated experiments |
| Selected figures, no renderer | Not baseline-tested | Use available official image/viewer if possible; otherwise record locator and limitation |
| Critic finds leakage after Strong rating | Not baseline-tested | Revise support with reason/location, flag dependent content, preserve author claim |

All seven updated cases produced the expected decisions. This does not establish actual PDF crop quality, visual recognition accuracy, or real-world search completeness. Those require representative papers and tool-enabled execution.

## Local checks

- Repository validator: skill structure, reference resolution, temporary installation, byte-for-byte installed resource preservation.
- Skill-creator quick validator: frontmatter and skill metadata.
- Git whitespace/error check.
- Regression fixtures: missing referenced figure guide and an installer omitting that guide must both be rejected.
